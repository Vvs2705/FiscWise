# ContaFlow - Guia de Deployment

Este guia fornece instruções completas para fazer deploy do ContaFlow em produção usando Railway (backend) e Vercel (frontend).

## 📋 Pré-requisitos

- Conta no [Railway](https://railway.app)
- Conta no [Vercel](https://vercel.com)
- Conta no [GitHub](https://github.com)
- API Keys:
  - Anthropic Claude API Key
  - Voyage AI API Key

## 🚀 Deploy do Backend (Railway)

### 1. Criar Projeto no Railway

1. Acesse [railway.app](https://railway.app) e faça login
2. Clique em "New Project"
3. Selecione "Deploy from GitHub repo"
4. Conecte seu repositório ContaFlow
5. Selecione a branch `main`

### 2. Adicionar PostgreSQL

1. No projeto Railway, clique em "+ New"
2. Selecione "Database" → "PostgreSQL"
3. Railway criará automaticamente a variável `DATABASE_URL`

### 3. Habilitar pgvector Extension

```bash
# Instalar Railway CLI
npm install -g @railway/cli

# Login
railway login

# Link ao projeto
railway link

# Habilitar pgvector
railway run psql -c "CREATE EXTENSION IF NOT EXISTS vector;"
```

### 4. Adicionar Redis

1. No projeto Railway, clique em "+ New"
2. Selecione "Database" → "Redis"
3. Railway criará automaticamente a variável `REDIS_URL`

### 5. Configurar Environment Variables

No painel do Railway, adicione as seguintes variáveis:

```env
# Geradas automaticamente pelo Railway
DATABASE_URL=<auto-generated>
REDIS_URL=<auto-generated>

# Configurar manualmente
SECRET_KEY=<generate-with-openssl-rand-hex-32>
ANTHROPIC_API_KEY=sk-ant-...
VOYAGE_API_KEY=pa-...
ALLOWED_ORIGINS=https://contaflow.vercel.app
TOP_K_RESULTS=5
CHUNK_SIZE=1000
CHUNK_OVERLAP=200
```

**Gerar SECRET_KEY:**
```bash
openssl rand -hex 32
```

### 6. Deploy

O deploy acontece automaticamente quando você faz push para `main`:

```bash
git add .
git commit -m "Deploy to production"
git push origin main
```

Railway detectará o `railway.toml` e fará o deploy automaticamente.

### 7. Verificar Deploy

Acesse a URL gerada pelo Railway (ex: `https://contaflow-production.up.railway.app`)

```bash
curl https://contaflow-production.up.railway.app/api/v1/health
```

Resposta esperada:
```json
{
  "status": "healthy",
  "service": "contaflow-api",
  "version": "1.0.0"
}
```

## 🎨 Deploy do Frontend (Vercel)

### 1. Importar Projeto

1. Acesse [vercel.com](https://vercel.com) e faça login
2. Clique em "Add New" → "Project"
3. Importe o repositório ContaFlow do GitHub
4. Configure:
   - **Framework Preset:** Vite
   - **Root Directory:** `frontend`
   - **Build Command:** `npm run build`
   - **Output Directory:** `dist`

### 2. Configurar Environment Variables

No painel do Vercel, adicione:

```env
VITE_API_URL=https://contaflow-production.up.railway.app
VITE_APP_NAME=ContaFlow
```

### 3. Deploy

Clique em "Deploy". O Vercel fará o build e deploy automaticamente.

### 4. Verificar Deploy

Acesse a URL gerada pelo Vercel (ex: `https://contaflow.vercel.app`)

## 🔄 CI/CD com GitHub Actions

### 1. Configurar Secrets no GitHub

No repositório GitHub, vá em Settings → Secrets and variables → Actions:

**Backend (Railway):**
- `RAILWAY_TOKEN` - Token de API do Railway
- `RAILWAY_PROJECT_ID` - ID do projeto Railway
- `ANTHROPIC_API_KEY` - Para testes
- `VOYAGE_API_KEY` - Para testes

**Frontend (Vercel):**
- `VERCEL_TOKEN` - Token de API do Vercel
- `VERCEL_ORG_ID` - ID da organização Vercel
- `VERCEL_PROJECT_ID` - ID do projeto Vercel

### 2. Obter Tokens

**Railway Token:**
```bash
railway login
railway whoami --token
```

**Vercel Token:**
1. Acesse [vercel.com/account/tokens](https://vercel.com/account/tokens)
2. Crie um novo token
3. Copie o token

**Vercel Org ID e Project ID:**
```bash
# Instalar Vercel CLI
npm install -g vercel

# Login
vercel login

# Link ao projeto
cd frontend
vercel link

# IDs estarão em .vercel/project.json
cat .vercel/project.json
```

### 3. Workflows Configurados

**Backend CI** (`.github/workflows/backend-ci.yml`):
- Roda em push/PR para `backend/**`
- Testa com PostgreSQL + Redis
- Executa linter (Ruff) e type checker (MyPy)
- Roda testes com pytest
- Build Docker image

**Deploy** (`.github/workflows/deploy.yml`):
- Roda em push para `main`
- Deploy backend para Railway
- Deploy frontend para Vercel
- Notificação de status

## 🔧 Configuração de Custom Domain (Opcional)

### Backend (Railway)

1. No projeto Railway, vá em Settings → Domains
2. Clique em "Add Domain"
3. Digite: `api.contaflow.com`
4. Configure DNS:
   ```
   CNAME api.contaflow.com → contaflow-production.up.railway.app
   ```
5. Railway provisiona SSL automaticamente

### Frontend (Vercel)

1. No projeto Vercel, vá em Settings → Domains
2. Clique em "Add"
3. Digite: `app.contaflow.com`
4. Configure DNS:
   ```
   CNAME app.contaflow.com → cname.vercel-dns.com
   ```
5. Vercel provisiona SSL automaticamente

## 💾 Backup do Banco de Dados

### Backup Manual

```bash
# Backup
railway run pg_dump $DATABASE_URL > backup_$(date +%Y%m%d_%H%M%S).sql

# Restore
railway run psql $DATABASE_URL < backup_20260427_140000.sql
```

### Backup Automático

Railway faz backups automáticos do PostgreSQL. Para acessar:

1. Vá no serviço PostgreSQL
2. Clique em "Backups"
3. Selecione o backup desejado

## 🐛 Troubleshooting

### Backend não inicia

1. Verificar logs: `railway logs`
2. Verificar environment variables
3. Verificar se pgvector está habilitado
4. Verificar migrations: `railway run alembic current`

### Frontend não conecta ao backend

1. Verificar `VITE_API_URL` no Vercel
2. Verificar CORS no backend (`ALLOWED_ORIGINS`)
3. Verificar se backend está rodando: `curl <backend-url>/api/v1/health`

### Migrations falhando

```bash
# Ver status das migrations
railway run alembic current

# Aplicar migrations manualmente
railway run alembic upgrade head

# Reverter migration
railway run alembic downgrade -1
```
